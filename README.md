# Ninja Battle: Chakra Showdown 🥷💥

An action-packed 2D ninja battle browser game featuring Naruto Uzumaki and Sasuke Uchiha! Experience dynamic combat, chakra management, particle effects, character selection, high scores, and cinematic ultimate jutsu video blends.

![Ninja Battle](index.html)

---

## 🌟 Key Features

- **Character Selection**: Play as **Naruto Uzumaki** (Wind Affinity, fast chakra regen, Shadow Clones) or **Sasuke Uchiha** (Lightning/Fire Affinity, high damage, Chidori & Sharingan).
- **Cinematic Ultimate Jutsu**: Special video cinematic blends for game-changing ultimate attacks.
- **Dynamic Combat System**: Light attack, heavy attack, dodge rolls, chakra charging, and special abilities.
- **Particle & Visual Effects**: Custom HTML5 Canvas particle renderer for slash effects, fireballs, chakra surges, and hit impacts.
- **High Scores & Upgrades**: Local storage persistence for high scores and character stat upgrades.
- **Responsive Controls**: Full keyboard and touch control support.

---

## 🎮 How to Play

1. Open `index.html` in any modern web browser.
2. Select your Shinobi character.
3. Use the controls:
   - **Move Left / Right**: `A` / `D` or `Left Arrow` / `Right Arrow`
   - **Jump**: `W` or `Up Arrow` / `Space`
   - **Basic Attack**: `J` or `Z`
   - **Special Skill**: `K` or `X`
   - **Ultimate Jutsu**: `L` or `C` (Requires 100% Chakra)
   - **Charge Chakra**: Hold `S` or `Down Arrow`

---

## 🛠️ Tech Stack

- **HTML5**: Game structure and canvas rendering element.
- **Vanilla CSS3**: Modern styling, glassmorphism UI, glowing effects, and responsive screens.
- **JavaScript (ES6+)**: Custom game loop, collision detection, particle physics, and state management.
